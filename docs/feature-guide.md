# 기능 설명서

이 문서는 `통계연보 검수 보조` 프로젝트를 처음 사용하는 사람이 화면에서 어떤 기능을 어디서 찾고, 어떤 순서로 사용하면 되는지 알 수 있도록 정리한 사용자 안내서입니다.

## 시작하기

로컬에서 실행한 뒤 브라우저로 `http://127.0.0.1:5173`에 접속합니다.

화면 상단에는 다음 메뉴와 버튼이 있습니다.

| 위치 | 이름 | 용도 |
| --- | --- | --- |
| 상단 왼쪽 | 통계 연보 검수 보조 | 서비스 이름입니다. |
| 상단 버튼 | 연보 업로드 | 완성 연보 파일을 업로드하거나 원장 Excel로 새 연도 연보를 생성합니다. |
| 상단 버튼 | 연보 비교 | 두 연보 스냅샷의 표·셀 차이를 비교합니다. |
| 상단 메뉴 | 통계 연보 | 업로드된 연보를 조회하고 검수 결과를 확인합니다. |
| 상단 메뉴 | 통계 원장 | 원천 시스템에서 적재한 통계 원장 데이터를 조회합니다. |
| 상단 메뉴 | 주요통계집 | 주요통계집 기준 자료를 같은 작업 화면으로 조회합니다. |
| 상단 메뉴 | 수정 권한 | 통계표별 수정 비밀번호를 관리합니다. |

## 전체 사용 흐름

처음 사용하는 경우에는 아래 순서대로 진행하면 됩니다.

1. `연보 업로드`로 검수할 연보를 등록합니다.
2. `통계 연보` 화면에서 등록된 연보를 선택합니다.
3. 표 목록에서 검토할 표를 검색하거나 상태별로 필터링합니다.
4. `검수 진행`을 눌러 필요한 검수 항목을 선택하고 실행합니다.
5. 표 목록과 상세 화면에서 `정상`, `확인 필요`, `오류 의심` 항목을 확인합니다.
6. 필요하면 상세 화면의 `수정` 기능으로 표 내용을 수정합니다.
7. 수정 후 다시 `검수 진행`을 실행해 최신 검수 결과를 만듭니다.
8. 필요한 표 또는 연보 전체를 Excel/CSV로 다운로드합니다.

## 1. 연보 업로드

상단의 `연보 업로드` 버튼을 누르면 업로드 대화상자가 열립니다.

### 완성 연보 새로 업로드

이미 완성된 연보 문서를 시스템에 등록할 때 사용합니다.

사용 순서:

1. `연보 업로드`를 누릅니다.
2. `완성 연보 새로 업로드`를 선택합니다.
3. `대상 연도`를 입력합니다.
4. `연보 이름`을 입력합니다.
5. `연보 파일 선택`을 눌러 파일을 선택합니다.
6. `업로드 시작`을 누릅니다.
7. 처리가 완료되면 생성된 연보가 자동으로 선택됩니다.

지원 파일:

- `.hwpx`
- `.md`

백엔드 파서는 `.xlsx`도 처리할 수 있지만, 현재 화면의 완성 연보 파일 선택창은 `.hwpx`, `.md`를 받도록 되어 있습니다.

처리 과정:

- 원본 파일에서 통계표를 추출합니다.
- 표 번호, 제목, 행렬 구조, 셀 좌표를 검증합니다.
- 연보, 통계표, 셀 데이터를 DB에 저장합니다.
- 업로드 작업 상태를 폴링해 완료 여부를 확인합니다.

주의할 점:

- 표 번호가 없거나 중복되면 업로드가 실패할 수 있습니다.
- 저장 가능한 통계표를 찾지 못하면 업로드가 실패합니다.
- 작업 실패 시 시스템은 자동으로 1회 재시도합니다.

### 기준 연보에 새 연도 원장 추가

원천 시스템에서 받은 Excel 3종을 사용해 기준 연보 형식에 새 연도 데이터를 반영할 때 사용합니다.

사용 순서:

1. `연보 업로드`를 누릅니다.
2. `기준 연보에 새 연도 원장 추가`를 선택합니다.
3. `대상 연도`를 입력합니다.
4. `기준 연보`를 선택합니다.
5. `연보 이름`을 입력합니다.
6. `표정보`, `표항목`, `표데이터` 파일을 각각 선택합니다.
7. `업로드 시작`을 누릅니다.
8. 완료 알림에서 신규·갱신·동일 값 수와 생성 표 수를 확인합니다.

필요 파일:

- `표정보` Excel
- `표항목` Excel
- `표데이터` Excel

지원 파일 형식:

- `.xls`
- `.xlsx`

처리 결과:

- 원장 값이 별도 원장 테이블에 적재됩니다.
- 기준 연보 레이아웃과 갱신 정책을 사용해 새 연도 연보가 만들어집니다.
- 생성하지 못한 표도 숨기지 않고 `확인 필요` 또는 실패 상태로 표시합니다.
- 이 방식으로 만든 테스트 연보는 생성 상태 확인용이며 검수를 실행하지 않습니다.

## 2. 통계 연보 화면

`통계 연보` 메뉴는 가장 많이 사용하는 메인 작업 화면입니다.

화면은 크게 세 영역으로 나뉩니다.

| 영역 | 설명 |
| --- | --- |
| 좌측 상단 요약 패널 | 연보 선택, 상태 요약, 검수 실행, 다운로드, 삭제 |
| 좌측 하단 표 목록 | 표 검색, 상태 필터, 표 선택 |
| 우측 미리보기 | 선택한 표의 요약, 검수 결과, 원본 표 일부 표시 |

### 연보 선택

요약 패널 상단의 드롭다운에서 조회할 연보를 선택합니다.

표시 정보:

- 연보 이름
- 수록 표 개수
- 테스트 연보 여부

선택을 바꾸면 표 목록, 요약, 상세 데이터가 선택한 연보 기준으로 다시 불러와집니다.

### 상태 요약 카드

요약 패널에는 네 가지 상태 카드가 있습니다.

| 카드 | 의미 | 클릭 시 동작 |
| --- | --- | --- |
| 전체 표 | 해당 연보의 전체 통계표 수 | 전체 표 목록 표시 |
| 정상 | 검수 결과 문제가 없는 표 | 정상 표만 필터링 |
| 확인 필요 | 담당자 확인이 필요한 표 | 확인 필요 표만 필터링 |
| 오류 의심 | 계산 오류 등 오류 가능성이 큰 표 | 오류 의심 표만 필터링 |

테스트 연보에서는 `정상`, `확인 필요`, `오류 의심`이 각각 생성 가능, 생성 확인, 생성 실패 의미로 표시됩니다.

### 표 검색과 필터

표 목록 위의 검색창에서 표 번호나 제목을 검색할 수 있습니다.

필터 옵션:

- `전체`
- `정상`
- `확인 필요`
- `오류 의심`
- `검수 항목`

`검수 항목`은 정상 여부와 관계없이 검수 결과가 붙어 있는 표를 찾을 때 사용합니다.

### 표 선택과 상세 보기

표 목록에서 한 번 클릭하면 오른쪽 미리보기가 바뀝니다. 표 목록에서 더블 클릭하거나 오른쪽 미리보기의 `상세 보기`를 누르면 상세 화면으로 이동합니다.

미리보기에서 확인할 수 있는 정보:

- 표 번호
- 표 제목과 영문 제목
- 분야, 기준일, 단위
- 자동 요약
- 주요 검수 결과
- 원본 표 일부
- 테스트 연보인 경우 생성 상태와 연결 원장 정보

현재 미리보기 하단의 `다운로드`, `메타정보` 버튼은 표시용 버튼이며, 실제 표 다운로드와 메타정보 확인은 상세 화면에서 사용하는 것이 좋습니다.

## 3. 검수 진행

요약 패널의 `검수 진행` 버튼을 누르면 검수 항목 선택 창이 열립니다.

### 검수 항목

| 항목 | 언제 사용하나 |
| --- | --- |
| 합계 검수 | 행·열 합계, 소계, 계 값이 맞는지 확인할 때 |
| 비율 검수 | 비율, 비중, 잔액율처럼 계산 가능한 퍼센트 값을 확인할 때 |
| 증감률 검수 | 전년 대비 증감액과 증감률을 확인할 때 |
| 오탈자 검수 | 국문·영문 철자, 문자 깨짐, 숫자 표기 오류를 찾을 때 |
| 번역 검수 | 국문 제목·항목과 영문 번역의 의미 대응을 볼 때 |
| 메타정보 검수 | 단위, 기준일, 출처 같은 필수 정보 누락을 확인할 때 |
| 이상치 검수 | 시계열이나 같은 열 안에서 튀는 값을 찾을 때 |
| 파란색 표기 확인 | HWPX 원문에서 파란색으로 표시된 검토 대상을 확인할 때 |

### 실행 옵션

`전체 선택`과 `전체 해제`로 검수 항목을 빠르게 조정할 수 있습니다.

`기존 검수 결과 재사용`을 켜면 이전 검수 실행에서 같은 표의 결과를 복사합니다. 단, 표 구조와 셀 값이 완전히 같은 표만 재사용합니다.

`재사용할 검수 실행` 드롭다운에서는 특정 연보의 이전 검수 결과를 재사용 대상으로 지정할 수 있습니다. 선택한 실행에 현재 선택한 검수 항목이 포함되어 있지 않으면 해당 실행은 선택할 수 없습니다.

`언어 후보 LLM 자동 판정`은 오탈자 검수나 번역 검수를 선택했을 때만 사용할 수 있습니다. 이 옵션을 켜면 대기 중인 언어 후보를 LLM으로 자동 판정합니다.

### 추천 사용 방식

처음 검수할 때:

1. 모든 검수 항목을 선택합니다.
2. LLM 비용을 쓰지 않을 경우 `언어 후보 LLM 자동 판정`은 끕니다.
3. `검수 실행`을 누릅니다.

문서가 일부 수정된 뒤 다시 검수할 때:

1. 필요한 검수 항목만 선택합니다.
2. `기존 검수 결과 재사용`을 켭니다.
3. 변경된 표만 새로 검수되는지 완료 알림의 재사용 표 수를 확인합니다.

언어 검수를 마무리해야 할 때:

1. `오탈자 검수`, `번역 검수`를 선택합니다.
2. `언어 후보 LLM 자동 판정`을 켭니다.
3. 검수 완료 후 언어 대기 후보가 줄었는지 확인합니다.

## 4. 검수 결과 확인

검수가 완료되면 표 목록과 상세 화면에서 결과를 확인합니다.

### 상태 의미

| 상태 | 의미 | 권장 조치 |
| --- | --- | --- |
| 정상 | 자동 검수에서 문제가 발견되지 않음 | 별도 조치 없이 통과 가능 |
| 확인 필요 | 오류라고 단정할 수 없지만 담당자 확인이 필요함 | 출처, 단위, 번역, 이상치 등을 확인 |
| 오류 의심 | 계산값 불일치 등 오류 가능성이 큼 | 원본 값과 산식 기준을 우선 확인 |

### 검수 유형 표시/숨김

요약 패널의 검수 유형 필터에서 특정 검수 유형을 숨기거나 다시 보이게 할 수 있습니다.

사용 예:

- 계산 오류만 보고 싶으면 오탈자·번역·메타정보 유형을 숨깁니다.
- 언어 검수만 보고 싶으면 합계·비율·이상치 유형을 숨깁니다.
- 발표나 보고용으로 오류 수를 줄여 보여줘야 할 때 특정 유형을 잠시 숨깁니다.

숨김은 화면 표시만 바꾸며, DB에 저장된 검수 결과를 삭제하지 않습니다.

## 5. 표 상세 화면

상세 화면에서는 표 하나의 데이터와 검수 결과를 깊게 확인합니다.

진입 방법:

- 표 목록에서 표를 더블 클릭합니다.
- 미리보기의 `상세 보기`를 누릅니다.

주요 영역:

| 영역 | 설명 |
| --- | --- |
| 상단 제목 영역 | 표 번호, 상위 분류, 제목, 영문 제목, 상태 |
| 메타 스트립 | 기준일, 단위, 최종 수정일 등 핵심 메타정보 |
| 원본 표 영역 | 실제 표 데이터를 그리드로 표시 |
| 분석 패널 | 검수 결과, 메타정보, 시각화 등 탭형 정보 |
| 다운로드 메뉴 | 선택 표를 CSV 또는 XLSX로 다운로드 |
| 수정 버튼 | 비밀번호 인증 후 표 수정 모드로 전환 |

상세 화면에서는 검수 결과가 셀 또는 행 단위로 하이라이트됩니다. 검수 결과 목록에서 항목을 선택하면 어떤 행·열·값이 문제인지 더 쉽게 확인할 수 있습니다.

## 6. 표 수정

상세 화면의 `수정` 버튼을 누르면 비밀번호 입력 창이 열립니다.

### 수정 시작

사용 순서:

1. `통계 연보`에서 수정할 연보를 선택합니다.
2. 표 상세 화면으로 들어갑니다.
3. `수정`을 누릅니다.
4. 통계에 설정된 비밀번호를 입력합니다.
5. `수정 시작`을 누릅니다.

초기 비밀번호:

- 담당 주무관 유선번호의 마지막 네 자리
- 담당 번호가 없으면 `0000`

### 수정할 수 있는 항목

수정 모드에서 다음 항목을 바꿀 수 있습니다.

- 표 번호
- 표 제목
- 영문 제목
- 상위 분류명
- 기준일
- 단위
- 열 제목과 영문 열 제목
- 각 셀 값
- 출처·담당자·연락처 등 메타정보

하위 표가 있는 경우 하위 표 탭을 선택해 각 하위 표를 수정할 수 있습니다.

### 저장과 재검수

수정 후 `완료`를 누르면 변경 내용이 저장됩니다. 저장된 표는 이전 검수 결과보다 최신 상태가 되므로, 정확한 결과를 보려면 다시 `검수 진행`을 실행하는 것이 좋습니다.

주의할 점:

- 표 번호가 중복되면 저장할 수 없습니다.
- 저장하지 않고 뒤로 가면 변경 내용을 버릴지 확인합니다.
- 수정 후 이전 검수 결과가 오래된 결과로 보일 수 있습니다.

## 7. 수정 권한 관리

상단 메뉴의 `수정 권한`에서 통계표별 수정 비밀번호를 관리합니다.

사용 순서:

1. `수정 권한` 메뉴를 엽니다.
2. 대상 연보를 선택합니다.
3. 검색창에서 통계 번호, 제목, 담당자를 검색합니다.
4. 원하는 통계의 `비밀번호 변경`을 누릅니다.
5. 현재 비밀번호를 입력합니다.
6. 새 비밀번호와 확인값을 입력합니다.
7. `저장`을 누릅니다.

상태 표시:

- `초기 비밀번호`: 아직 기본 비밀번호를 사용 중입니다.
- `변경됨`: 사용자가 새 비밀번호로 변경했습니다.

비밀번호는 4자 이상이어야 하며, 새 비밀번호와 확인값이 같아야 저장할 수 있습니다.

## 8. 다운로드

이 프로젝트는 표 단위 다운로드와 연보 단위 다운로드를 제공합니다.

### 표 단위 다운로드

상세 화면 오른쪽 상단의 `다운로드` 메뉴를 사용합니다.

지원 형식:

- CSV
- XLSX

표에 하위 표가 있으면 하위 표 구조를 포함해 다운로드 파일이 만들어집니다.

### 연보 단위 다운로드

요약 패널의 `연보 다운` 버튼을 사용합니다.

사용 순서:

1. `통계 연보` 화면에서 다운로드할 연보를 선택합니다.
2. 요약 패널의 `연보 다운`을 누릅니다.
3. 통계 번호 목록이 뜨면 전체 선택 또는 필요한 표만 선택합니다.
4. `다운로드`를 누릅니다.
5. 진행률을 확인합니다.
6. Excel 파일이 생성되면 브라우저가 파일을 내려받습니다.

주의할 점:

- 테스트 연보는 다운로드 대상에서 제외됩니다.
- 선택한 표가 많으면 각 표 상세 데이터를 순차로 불러오므로 시간이 걸릴 수 있습니다.

## 9. 연보 비교

상단의 `연보 비교` 버튼으로 두 연보를 비교할 수 있습니다.

사용 순서:

1. `연보 비교`를 누릅니다.
2. `기준 연보`를 선택합니다.
3. `비교 연보`를 선택합니다.
4. `비교 실행`을 누릅니다.
5. 요약 수치와 표별 차이를 확인합니다.

비교 결과:

- 일치 표 수
- 변경 표 수
- 추가 표 수
- 삭제 표 수
- 변경 셀 수
- 표별 변경 유형
- 표별 주요 셀 차이

사용 예:

- 원장 기반으로 생성한 연보와 완성 연보가 얼마나 다른지 확인합니다.
- 수정 전후 연보의 차이를 확인합니다.
- 기준 연보와 다음 연도 연보의 구조 차이를 확인합니다.

주의할 점:

- 비교하려면 연보가 두 개 이상 있어야 합니다.
- 같은 연보끼리는 비교할 수 없습니다.
- 테스트 연보는 비교 목록에서 제외됩니다.

## 10. 통계 원장

`통계 원장` 메뉴에서는 원천 시스템에서 적재한 통계 데이터를 조회합니다.

화면 구성:

| 영역 | 설명 |
| --- | --- |
| 상단 요약 | 전체 통계 수, 데이터 보유 통계 수, 원장 셀 수, 수록 범위 |
| 왼쪽 목록 | 통계 ID, 통계명, 부서, 보유 기간 |
| 오른쪽 상세 | 선택한 통계의 기준시점별 데이터 |

사용 순서:

1. `통계 원장` 메뉴를 엽니다.
2. 왼쪽 검색창에서 통계명, 표 ID, 부서를 검색합니다.
3. 통계를 선택합니다.
4. 오른쪽의 `기준시점` 드롭다운에서 조회할 기간을 선택합니다.
5. 항목, 행 수, 자료시점, 입력상태를 확인합니다.

사용 예:

- 연보에 반영된 값이 실제 원장 값과 일치하는지 확인합니다.
- 특정 통계가 어떤 기간의 데이터를 보유하는지 확인합니다.
- 기준 연보에 새 연도 원장을 추가하기 전 원천 데이터 상태를 점검합니다.


## 11. 연보 삭제

요약 패널의 `연보 삭제` 버튼으로 선택한 연보를 삭제할 수 있습니다.

사용 순서:

1. 삭제할 연보를 선택합니다.
2. `연보 삭제`를 누릅니다.
3. 확인 창에서 삭제 대상과 함께 삭제될 표·검수 결과 수를 확인합니다.
4. 확인하면 연보와 연결된 데이터가 삭제됩니다.

주의할 점:

- 삭제한 연보는 되돌릴 수 없습니다.
- 테스트 연보는 삭제 버튼이 표시되지 않습니다.
- 삭제 시 표와 연결된 검수 실행도 함께 정리됩니다.

## 13. 상태와 메시지 이해하기

### 검수 상태

| 표시 | 의미 |
| --- | --- |
| 정상 | 자동 검수에서 문제 없음 |
| 확인 필요 | 담당자 판단이 필요한 후보 있음 |
| 오류 의심 | 계산 또는 값 불일치 가능성이 큼 |

### 생성 상태

원장 기반 생성 연보에서는 검수 상태 대신 생성 상태를 확인합니다.

| 표시 | 의미 |
| --- | --- |
| 생성 가능 | 기준 연보 구조에 원장 값을 반영할 수 있음 |
| 생성 확인 | 연결 원장, 갱신 정책, 일부 값 확인 필요 |
| 생성 실패 | 필요한 원장 또는 구조 정보가 부족해 자동 생성 실패 |

### 업로드 작업 상태

| 상태 | 의미 |
| --- | --- |
| queued | 작업 대기 중 |
| running | 처리 중 |
| completed | 완료 |
| failed | 실패 |

업로드가 실패하면 오류 메시지를 확인하고, 파일 형식·연도·표 구조·필수 파일 선택 여부를 먼저 점검합니다.

## 14. 상황별 사용 예시

### 새 완성 연보를 처음 검수하는 경우

1. `연보 업로드`에서 `완성 연보 새로 업로드`를 선택합니다.
2. 대상 연도, 연보 이름, HWPX 또는 Markdown 파일을 선택합니다.
3. 업로드 완료 후 `통계 연보` 화면에서 생성된 연보를 선택합니다.
4. `검수 진행`을 열고 전체 항목을 선택합니다.
5. 필요하면 `언어 후보 LLM 자동 판정`을 켭니다.
6. 검수가 끝나면 `오류 의심` 필터부터 확인합니다.
7. 이어서 `확인 필요` 필터를 확인합니다.
8. 상세 화면에서 문제 위치를 확인하고 필요한 표를 수정합니다.
9. 수정 후 다시 검수합니다.

### 원장 Excel로 다음 연도 연보를 생성하는 경우

1. `연보 업로드`에서 `기준 연보에 새 연도 원장 추가`를 선택합니다.
2. 기준 연보를 선택합니다.
3. 대상 연도를 입력합니다.
4. `표정보`, `표항목`, `표데이터` 파일을 선택합니다.
5. 업로드를 시작합니다.
6. 완료 알림에서 원장 값 반영 수와 생성 표 수를 확인합니다.
7. `통계 연보`에서 테스트 연보의 생성 가능·확인·실패 표를 확인합니다.
8. `통계 원장`에서 연결 원장의 세부 값을 조회합니다.
9. 필요하면 `연보 비교`로 기준 연보 또는 완성 연보와 차이를 비교합니다.

### 특정 표 하나만 내려받는 경우

1. `통계 연보`에서 연보를 선택합니다.
2. 표 목록에서 원하는 표를 검색합니다.
3. 상세 화면으로 들어갑니다.
4. `다운로드` 메뉴에서 CSV 또는 XLSX를 선택합니다.

### 담당자가 표 값을 수정하는 경우

1. `수정 권한`에서 해당 통계의 비밀번호 상태를 확인합니다.
2. 필요하면 비밀번호를 변경합니다.
3. `통계 연보`에서 수정할 표 상세 화면으로 이동합니다.
4. `수정`을 누르고 비밀번호를 입력합니다.
5. 표 제목, 셀, 메타정보를 수정합니다.
6. `완료`를 눌러 저장합니다.
7. 다시 `검수 진행`을 실행합니다.

## 15. 문제가 생겼을 때 확인할 것

업로드 버튼이 활성화되지 않을 때:

- 대상 연도가 4자리인지 확인합니다.
- 연보 이름이 비어 있지 않은지 확인합니다.
- 완성 연보 업로드라면 파일 1개를 선택했는지 확인합니다.
- 원장 추가라면 `표정보`, `표항목`, `표데이터` 세 파일을 모두 선택했는지 확인합니다.

검수 진행 버튼이 보이지 않을 때:

- 테스트 연보를 선택했는지 확인합니다. 테스트 연보는 검수를 실행하지 않습니다.
- 연보가 정상적으로 선택되어 있는지 확인합니다.
- 연보에 표가 있는지 확인합니다.

수정이 되지 않을 때:

- 올바른 비밀번호를 입력했는지 확인합니다.
- 초기 비밀번호는 담당 주무관 유선번호 마지막 네 자리 또는 `0000`입니다.
- 표 번호가 다른 표와 중복되지 않는지 확인합니다.
- 저장 후 이전 검수 결과가 남아 있으면 다시 검수를 실행합니다.

다운로드가 되지 않을 때:

- 테스트 연보를 선택했는지 확인합니다.
- 연보 다운로드에서는 최소 1개 표를 선택해야 합니다.
- 표가 많은 경우 다운로드 생성 시간이 걸릴 수 있습니다.

원장 데이터가 보이지 않을 때:

- 원장 Excel 3종이 정상 적재되었는지 확인합니다.
- `통계 원장` 검색어를 지우고 전체 목록을 확인합니다.
- 선택한 통계에 값이 없는 기간일 수 있으니 기준시점을 바꿔 봅니다.

| 하고 싶은 일 | 이동 경로 |
| --- | --- |
| 새 연보 업로드 | `연보 업로드` → `완성 연보 새로 업로드` |
| 원장으로 다음 연도 생성 | `연보 업로드` → `기준 연보에 새 연도 원장 추가` |
| 검수 실행 | `통계 연보` → 연보 선택 → `검수 진행` |
| 오류 표만 보기 | `통계 연보` → `오류 의심` 카드 또는 필터 |
| 표 상세 확인 | `통계 연보` → 표 선택 → `상세 보기` |

| 비밀번호 변경 | `수정 권한` → 통계 검색 → `비밀번호 변경` |
| 표 CSV/XLSX 다운로드 | 표 상세 화면 → `다운로드` |
| 연보 Excel 다운로드 | `통계 연보` → `연보 다운` |
| 두 연보 비교 | 상단 `연보 비교` |
| 원장 값 조회 | `통계 원장` → 통계 검색 → 기준시점 선택 |
