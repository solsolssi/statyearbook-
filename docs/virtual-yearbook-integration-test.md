# 가상 통계연보 통합 테스트

실제 연보 전체를 반복 업로드하지 않고도 파싱, 증분 연결, 검수 재사용, LLM 보조, 수정·재검수, 검수 리포트를 확인하기 위한 고정 테스트 자료다. 모든 기관명·담당자·전화번호·수치는 가상이다.

## 파일

- `generated/virtual_yearbook_test/virtual_yearbook_v1_2027.md`: 20개 논리 통계의 최초 연보
- `generated/virtual_yearbook_test/virtual_yearbook_v2_2028.md`: 일부 동일, 일부 값·구조 변경, 신규 통계 1개가 포함된 21개 통계 연보
- `generated/virtual_yearbook_test/virtual_increment_2028_table_info.xlsx`: 증분 표정보
- `generated/virtual_yearbook_test/virtual_increment_2028_table_items.xlsx`: 증분 표항목
- `generated/virtual_yearbook_test/virtual_increment_2028_table_values.xlsx`: 증분 표데이터
- `generated/virtual_yearbook_test/fixture_manifest.json`: 통계 번호별 기대 결과

자료를 다시 만들 때는 저장소 루트에서 `.venv/bin/python backend/scripts/generate_virtual_yearbook_fixtures.py`를 실행한다.

## 권장 실행 순서

1. `virtual_yearbook_v1_2027.md`를 **전체 연보 업로드**로 올린다. 기본 파싱만 확인하려면 `파싱·표 구조 LLM 보조`를 끄고 시작한다.
2. 전체 검수 항목을 선택하되 `합계·비율 프로파일 LLM 보조`와 `오탈자·번역 LLM 검수`를 모두 끈다.
   - `9-1-3` 합계와 `9-1-5` 승인률은 오류 의심이어야 한다.
   - `9-3-1`~`9-3-3` 언어 후보는 재검수 필요로 남아야 한다.
   - `9-3-5`는 단위·기준일 누락으로 확인 필요여야 한다.
3. 같은 연보에서 기존 실행을 재사용하고 `오탈자·번역 LLM 검수`만 켜 재검수한다. 합계·비율 결과는 다시 계산하지 않고 언어 후보만 이어서 판정해야 한다. 실제 LLM 호출에는 서비스의 API 키 설정이 필요하다.
4. `9-1-3` 시스템 구축 합계 125를 120으로, `9-1-5`의 83.0을 80.0으로 수정한다. 저장 직후 해당 통계는 재검수 필요가 되어야 하고, 재검수 후 오류가 사라져야 한다.
5. v1을 기준 연보로 선택하고 세 증분 XLSX를 **증분 업로드**한다.
   - `9-2-1`: 2028 행을 추가하고 2023 행을 제거한다.
   - `9-2-2`: 2028 열을 추가하고 2023 열을 제거한다.
   - `9-2-3`: 부서별 스냅샷을 교체한다.
   - `9-2-4`: 병합된 상위 헤더 경로를 유지한 채 값을 반영한다.
   - `9-3-3`/`M-V-013`: 값이 없어 **증분 데이터 부족**이다.
   - `9-3-4`/`M-V-014`: 서로 다른 두 열에 같은 항목 설명이 중복되어 안전한 열 의미를 정할 수 없으므로 **형식 불일치**다.
   - `9-4-1`, `9-4-2`: 이름이 비슷하고 M키가 없는 기준 표다. `증분 연결 LLM 보조`의 보수적 연결 또는 확인 필요 유지 여부를 확인한다.
   - `M-V-021`: 신규 통계 `9-5-1` 후보이며, `M-V-020`은 삭제 명세다.
6. `virtual_yearbook_v2_2028.md`를 별도 전체 연보로 업로드한 뒤 v1 검수 실행을 재사용한다.
   - 완전히 같은 표는 이전 검수 결과를 재사용한다.
   - 값이 바뀐 `9-1-3`, `9-1-5`, `9-3-1`은 로컬 재검수한다.
   - 열 구조가 바뀐 `9-4-3`은 프로파일을 재생성하고 재검수한다.
   - 신규 `9-5-1`의 `c=a+b`는 규칙 기반 프로파일로 생성할 수 있다. 의미가 모호한 `품질지수`는 세 행 모두 `b/a×100`과 일치한다는 증거를 `합계·비율 프로파일 LLM 보조`가 검토하도록 한다.
7. 검수 후 **검수 리포트**에서 오류 의심, 확인 필요, 재검수 필요 상태를 원하는 조합으로 선택한다. ZIP 안에 메타데이터, 하이라이트 표, 검수 내역 XLSX 세 파일이 있어야 한다.

## LLM 옵션 경계

- 전체 연보 업로드의 LLM은 기존 파서가 헤더·단위·기준일을 확정하지 못한 표에만 사용한다. 정상 파싱된 표의 값이나 구조는 변경하지 않는다.
- 증분 LLM은 규칙 매처가 남긴 허용 후보 안에서만 M키 연결을 제안하며, 로컬 구조 미리보기를 통과하고 신뢰도가 높은 경우만 반영한다.
- 합계·비율 프로파일 LLM은 실행 가능한 검수 명세만 작성하고 계산은 항상 규칙 엔진이 수행한다.
- 오탈자·번역 LLM은 별도 옵션이다. 끄면 후보를 재검수 필요로 남기며, 이후 같은 실행에서 이어서 판정할 수 있다.
