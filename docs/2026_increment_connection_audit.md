# 2025 연보 + 2026 증분 연결 점검

기준: 2025 HWPX 연보 스냅샷과 2026 증분 원장(기준 데이터 2025년)만 사용했다. 이미 작성된 2026 연보는 연결·생성 입력으로 사용하지 않았다.

## 증분 원장이 있는 20개 물리 표

|분류|개수|표|
|---|---:|---|
|자동 연결 완료|8|2-2-12-3 표1, 3-2-1-1, 3-2-1-2, 4-1-1-3, 4-1-4-2, 8-1-3-2 표1·표2·표3|
|증분 내용이 연보 의미를 충족하지 않음|8|2-2-9 표2, 3-1-7-1, 3-1-10-1, 3-1-10-2, 5-2-1-5 표3, 6-2-4-3 표2, 6-3-3-3 표2, 8-1-1-1|
|새 레이아웃 또는 선행 이력 부족|4|8-1-4 표1, 6-3-3-1, 7-2-5-1, 7-3-6-1|

### 반영한 재사용 규칙

1. **기간창 이동**: 다년 표는 가장 오래된 연도 행(반복 구분 행 묶음 포함)을 제거하고 마지막 연도 행을 새 기준연도로 복제한다. 중간 연도 값은 이전 연보에서 그대로 이동하고, 새 기준연도만 증분 원장에서 채운다.
2. **확정 원장 연결의 기준연도**: 고정 기준연도가 없는 연결은 기준 연보에 적힌 과거 연도가 아니라 이번 증분의 목표 연도를 우선한다.
3. **명시 항목 투영**: 하나의 원장 통계가 여러 물리 표를 만들거나 `과정수`처럼 항목명이 반복될 때, 항목 번호를 명시하여 연보 열에 배치한다.
4. **공무용차량**: 원장 하위 항목을 `계·승용·승합·화물·특수` 열로 재배치한다.
5. **공공데이터 개방/민간활용**: 기관 구분 5행을 하나의 연도 묶음으로 보고 7개년 기간창을 이동한다.
6. **연도별 행정구역**: 기준일 행을 10개년 기간창으로 이동한다.
7. **유형별 의결 결과**: 인용·기각·각하는 원장에서 채우고 `계`는 세 행으로 다시 산출한다.
8. **사이버교육 3표**: 운영, 연계 운영, 공동활용의 서로 다른 하위 항목을 각 물리 표의 과정수·횟수·수료인원 열에 투영한다.

### 자동 연결하지 않은 12개와 이유

- **목록/서술형 원장으로 수치를 재현할 수 없음**: `2-2-9 표2`, `6-2-4-3 표2`, `6-3-3-3 표2`, `8-1-1-1`.
- **통계 의미가 바뀌었거나 다른 원장이 필요함**: `3-1-7-1`, `3-1-10-1`, `3-1-10-2`, `5-2-1-5 표3`.
- **새 항목 체계로 바뀜**: `6-3-3-1`, `7-2-5-1`, `7-3-6-1`.
- **선행 연보 이력이 표시 기간보다 짧음**: `8-1-4 표1`. 2012~2015만 있는 기준 표에 증분만으로 2025까지의 빠진 기간을 만들어낼 수 없다.

이 표들은 임의 연결 대신 `구조 변경/원장 범위 불일치`로 남긴다. 해당 증분 안에 없는 정보를 완성 2026 연보나 전체 원장에서 가져오지 않는다.
